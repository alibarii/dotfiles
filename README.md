# ⚙️ Dotfiles & Linux Environment Configurations

This repository contains my personal Linux environment configuration files, terminal aliases, and shell customization scripts used across my HomeLab and ASIR workstation setups.

---

## 📂 Included Configurations

- **`.bash_aliases`**: Useful command shortcuts for system administration, networking, and safety defaults.
- **`.bashrc`**: Custom prompt configuration and environment variables.

## 🚀 How to Apply These Aliases

To use these custom aliases on any Debian/Ubuntu/RedHat system:

1. Clone or download the `.bash_aliases` file to your home directory:
  bash
  curl -o ~/.bash_aliases https://raw.githubusercontent.com/tu-usuario/dotfiles/main/.bash_aliases

2. Reload your Bash configuration:
   bash
   source ~/.bashrc
